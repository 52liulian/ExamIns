# 考试指令播放系统

基于Python和PyQt5实现的考试指令播放系统。

## 功能特点

1. **两种考试模式**
   - 高考模式：严格按照高考时间安排
   - 普通模式：可自定义考试时间

2. **自动播放指令**
   - 根据考试时间自动播放相应的语音指令
   - 支持考前和考后指令
   - 实时显示系统时间和下一条指令

3. **完整的指令系统**
   - 包含完整的考试流程指令（入场检查、身份验证、分发试卷、开始答题、考试提醒、考试结束等）
   - 指令内容基于四川省高考指令系统

4. **图形化界面**
   - 简洁直观的用户界面
   - 支持查看完整指令列表
   - 实时显示当前状态

5. **网络校时功能**
   - 支持启动时自动网络校时，需要管理员权限启动
   - 可在主界面开启或关闭自动网络校时功能
   - 与多个NTP服务器同步时间

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用说明

1. **启动程序**

   ```bash
   python main.py
   ```

2. **选择考试模式**
   - 高考模式：选择科目后自动使用标准高考时间
   - 普通模式：选择科目并自定义开始和结束时间

3. **网络校时设置**
   - 在主界面可通过复选框开启或关闭"启动时自动网络校时"功能
   - 开启后，程序启动时会自动与NTP服务器同步系统时间
   - 设置会自动保存，下次启动时生效

4. **考试科目**
   - 高考模式：语文、数学、外语、物理、历史、化学、生物、地理、政治（3+1+2新高考模式）
   - 普通模式：语文、数学、历史、外语、化学、物理、生物、政治、地理、物理/历史、化学/政治、生物/地理、其他

5. **考试时间**
   - 高考模式（河南高考时间安排）：
     - 语文：09:00 - 11:30
     - 数学：15:00 - 17:00
     - 物理/历史：09:00 - 10:15
     - 外语：15:00 - 17:00
     - 化学：08:30 - 09:45
     - 思想政治：14:30 - 15:45
     - 地理：11:00 - 12:15
     - 生物学：17:00 - 18:15
   - 普通模式（根据提供的时间表）：
     - 语文：09:00 - 11:30
     - 数学：14:30 - 16:30
     - 历史：16:50 - 18:05
     - 外语：08:00 - 10:00
     - 化学：10:20 - 11:35
     - 物理：14:30 - 15:45
     - 生物：16:05 - 17:20
     - 政治：08:00 - 09:15
     - 地理：09:35 - 10:50
     - 物理/历史：10:30 - 11:45
     - 化学/政治：14:30 - 15:45
     - 生物/地理：15:55 - 17:10
     - 其他：可自定义时间

6. **指令播放**
   - 程序会根据考试时间自动计算并播放相应的语音指令
   - 可点击"查看指令列表"查看所有指令的播放时间
   - 可点击"停止"按钮停止当前考试并返回选择界面

## 注意事项

1. 确保Mp3文件夹中包含所有必要的音频文件
2. 音频文件命名必须与程序中定义的一致（p1.mp3 - p10.mp3）
3. 程序使用系统时间，请确保系统时间准确
4. 普通模式下，考试时间间隔不能少于1小时
5. 网络校时需要管理员权限才能修改系统时间
6. 如果没有管理员权限，网络校时会失败但不影响程序其他功能
7. 网络校时依赖网络连接，请确保设备已连接到网络
